## Project Goals

 - The initial goal is to recreate the fundamental functionality of a Discord music bot while learning more about the Discord API, asynchronous Python development, voice/audio streaming, and external API integrations.

 - Once the core music functionality is stable, the project can expand into more advanced features such as personalized autoplay, listening history, and recommendation algorithms.
